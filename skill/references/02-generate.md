## 6カテゴリ・バズパターン

### カテゴリ1: 失敗→AI逆転型（ストーリー型）★ 主力

**割合の目安**: 21本中 4-5本

**構造**:
```
[過去の具体的失敗を列挙]
   ↓
「そんな私が」「転機は」「Claude Code に頼んだ瞬間」
   ↓
[AI で挽回したエピソード]
   ↓
[気づき・感情]
   ↓
[読み手への問いかけ]
```

**例**:
```
最初の半年、Webサービスを10本ローンチして
9本は誰にも届きませんでした。

LP の1行目で詰まり
CPA が爆発し
リスト集約で迷子になり

正直、もう諦めかけていたんです。

転機は、Claude Code に
「過去の失敗 LP を全部読んで、共通点を教えて」
と頼んだ瞬間でした。

3年気づかなかったことを、AI は3秒で見抜く。
あの瞬間の悔しさと感謝、忘れません。

皆さんは、AI に「自分を分析」させたこと、ありますか？
```

**フックの作り方**:
- 具体的な数字（「10本中9本失敗」）
- 過去形・完了形（「失敗していました」）
- 感情語（「諦めかけていた」「悔しい」）

### カテゴリ2: マイルストーン報告型（数字・ビフォーアフ）

**割合の目安**: 21本中 3-4本

**構造**:
```
[期間 + 数字でフック]
   ↓
[ビフォーアフター・箇条書き]
   ↓
[本音・意外性]
   ↓
[読み手への問いかけ]
```

**例**:
```
1ヶ月前、Claude Code を本格導入しました。

結果：
・単純作業時間 1日3時間 → 30分
・リリースできたサービス 0本 → 2本
・撤退判断 「3週間悩む」→「3日で決める」

最初は半信半疑でした。
正直、AI に任せて良いのか怖かった。

でも、データが全部教えてくれました。
「人間がやらなくていい時間」が、こんなにあったんだなって。

皆さんは、AI に「任せきれない」と思う場面ってありますか？
```

**フックの作り方**:
- 「1ヶ月前、〜しました」「3週間で○○」
- 数字 + 期間
- 「結果：」で箇条書きに繋ぐ

### カテゴリ3: AI自動化メタ型（同業者刺さる）

**割合の目安**: 21本中 2-3本

**構造**:
```
[「AI に AI のことを任せた」フック]
   ↓
[具体的なやり方]
   ↓
[気づき・驚き]
   ↓
[読み手への問いかけ]
```

**例**:
```
Claude Code に、過去の自分のバズ投稿を全部読ませてみました。

「あなたが伸びる投稿の型は、これです」と
3パターン教えてくれたんです。

驚いたのは、自分でも気づいていなかった
「無意識のパターン」を抽出されたこと。

AI が自分のことを、自分より分かってる時代…
正直、ちょっとゾクッとしました。

皆さんも、AI に自分を分析させたこと、ありますか？
```

**フックの作り方**:
- 「Claude Code に〜させてみた」
- 「自分のバズパターンを学習させた」
- メタな視点（AI に AI を任せる）

### カテゴリ4: X vs Threads 比較・哲学（メタ的）

**割合の目安**: 21本中 1-2本

**構造**:
```
[両プラットフォームを比較]
   ↓
[数字 or 反応の質の違い]
   ↓
[気づき]
   ↓
[読み手の選択を聞く]
```

**例**:
```
X と Threads、同じテーマで投稿してみました。

X は「いいね30、引用RT5」
Threads は「いいね150、リプライ12」

数字より興味深かったのは、リプライの中身です。

X：「参考になりました」が中心
Threads：「私もこう感じました」が中心

同じ内容でも、反応の質が違うんですよね。

皆さんは、X 派？Threads 派？それとも両方？
```

### カテゴリ5: バズ後課題提起型（上級者向け）

**割合の目安**: 21本中 1-2本

**構造**:
```
[一見成功の数字]
   ↓
「でも実は…」転換
   ↓
[隠れた課題]
   ↓
[解決方向]
   ↓
[読み手の経験を聞く]
```

**例**:
```
1日で1万インプ出た投稿があったんですが、
売上には1円もつながりませんでした。

最初は「数字が出れば売れる」と思っていたんです。

でも、実際は違いました。
「読まれた数」と「行動された数」は別物。

その差を埋めるのが、導線設計と信頼貯金。
ここに気づいてから、私の発信は変わりました。

「インプが出ても売上が…」って経験、皆さんもありますか？
```

### カテゴリ6: 等身大・人間味型（オーセンティシティ）

**割合の目安**: 21本中 4-5本

**構造**:
```
[「正直に書きます」「実は」フック]
   ↓
[迷い・失敗・夜中の頭を抱えた話]
   ↓
[気づき・哲学]
   ↓
[読み手への問いかけ]
```

**例**:
```
正直に書きます。

昨日の夜、CLAUDE.md の書き方で2時間迷いました。

「公式通りに書くべきか」
「自分のスタイルで書くべきか」

結局、両方試して、自分のスタイルが
ちゃんと動くと分かりました。

ベストプラクティスが、自分にとっての最適とは限らない。
そんな当たり前のことを、夜中に再確認した時間でした。

皆さんも、「公式通り」で迷うこと、ありますか？
```

**フックの作り方**:
- 「正直に書きます」「実は」
- 「夜中に頭を抱えた」「2時間迷った」
- 弱さの開示

## ステップ

### Step 1. ネタリストから21本に展開

ネタ仕入れの出力を、6カテゴリに振り分け。

### Step 2. 各カテゴリの構造テンプレに沿って書く

`voice-guide.md` v2 のテンプレ参照。

### Step 3. 配分チェック

21本書いたら、カテゴリ・時間帯の配分を確認：
- 失敗→AI逆転 + 等身大が 60%以上
- 同じカテゴリを3投稿連続させない

### Step 4. 文字数チェック

最適: **200-400字**（40-120 words）
- 500字超は分割 or 削減
- 100字以下は薄すぎる

### Step 5. pending.md への書き込み

`~/atlier-base-v1/threads-workflow-repo/storage/stocks/pending.md` に Write。

各エントリのフォーマット：
```markdown
## YYYY-MM-DD-NNN
- 種類: 単発
- 投稿想定時刻: 朝（07:00-09:00） / 昼（11:00-15:00） / 夜（15:00-23:00）
- 想定日: YYYY-MM-DD（曜日）
- 軸: [カテゴリ名] #N
- 文面:

[全文・200-400字]

- ステータス: pending

---
```

## チェックリスト

各投稿について：

- [ ] **強いフック**（1行目で止まる）
- [ ] **シングルアイデア**（1投稿1テーマ）
- [ ] **「私」の体験が前面**

- [ ] **意見対立 or 共感誘発の問いかけ** で締め
- [ ] **絵文字 0-1個**（多用しない・ワンパターン回避）

- [ ] 専門用語は1文で解説
- [ ] **ですます調**（タメ口NG）
- [ ] 一人称「私」（「ひろ」は表示名のみ）
- [ ] 旧キャラ用語（店主・アトリエ）なし
- [ ] 本名「石井」「ミライ塾」なし

## よくある失敗パターン

1. **翻訳機になる**
   → 「翻訳した情報」が主役で「私」が脇役。NG。
   → 「私の体験」を主役にする

2. **形式的な問いかけ**
   → 「経験ありますか？」「どうですか？」だけだと弱い
   → 「A 派？B 派？」「賛成？反対？」で対立を呼ぶ

3. **同カテゴリ連続**
   → 3投稿連続で「失敗→AI逆転」だと飽きる
   → カテゴリを交互に並べる

4. **絵文字のワンパターン**
   → ☺️ ばかり使うと AI 生成感が出る
   → 内容に合わせて多様化（💡⚡🔧📐💭🎯など）
