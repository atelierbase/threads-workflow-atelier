## 背骨（X と共通・2026-06-01 v3.2）

「**20億円の事業を作ってきた実業家が、今は Claude Code / Codex を相棒に楽しくWebサービスを作っている**」。Threads では、その中で生まれた**失敗・成功・「この機能でこんな気づき！」**を共感ベースで語り、役立つので**最新情報もセット**で溶かし込む。20億円は時々だけ、静かな裏付けとして。

## ターゲット像（X と共通）

**メインターゲット**: **AIで事業作りしたい中級者**

- Claude Code を少し触ったことがある or 触ろうとしている
- 副業〜個人事業層
- 海外の最新AI情報を日本語でキャッチしたい
- AIを業務・事業に活かしたい

**取り込まない層**:
- AIに全く興味ない層
- 上級開発者で「日本語翻訳は不要」な層

## Threads 特性（X との本質的な違い）

2026年現在の調査で判明したこと：

### 場の性質
- X = **公共広場（Town Square）**: 議論・速報・トレンド
- Threads = **カフェ（Coffee Shop）**: 共感・対話・関係構築

### アルゴリズム
- X: リアルタイム性・話題性で評価
- Threads: **会話の深さ・関係性の強さ**で評価

### ユーザー態度
- X: 直接的な議論・批判OK
- Threads: **支持的・対立的反応に否定的**（より穏やか）

### エンゲージメント
- Threads は X より **+73.6% 高エンゲージメント**
- 同じ投稿で **2-3倍のエンゲ**になることも

### 収益化
- X: クリック・インプレッション・有料増幅
- Threads: **DM・温かいリード・信頼関係ベース**の販売

## 提供価値（フォローする理由・X と共通）

```
1. 海外で先行している Claude Code / Codex の最新情報を、日本語で翻訳
2. ひろ自身の AI 活用実例（数字とセット）
3. AI実業家としての視点・事業作りのリアル
```

ただし、Threads では **「対話できる仲間」** という関係性を最重視する。

## 主軸 × サブ軸（投稿配分・X と同じ）

| 軸 | 内容 | 配分 | 時間帯目安 |
|---|---|---|---|
| **主軸（海外翻訳）** | 海外で話題の Claude Code / Codex バズの日本語翻訳 | **50%** | 朝（07-09） |
| **サブ軸1（自分の実例）** | ひろが Claude Code / Codex を使った具体例・数字 | **30%** | 昼（12-13） |
| **サブ軸2（実業家視点）** | AIで事業作りのリアル・思考・哲学 | **20%** | 夜（19-22） |

## 発信の温度感（X との違い）

| 軸 | X 方針 | Threads 方針 |
|---|---|---|
| 教える / 見せる | 専門家として教える | **仲間として共有する** |
| 距離感 | 落ち着いた専門家 | **親しみやすい仲間** |
| 専門用語 | 必ず解説 | 必ず解説 + 「ご存知ですか？」 |
| 透明性 | 数字を具体的に | 数字＋感情 |

## コンテンツ生成の鉄則（必ず守る）

1. **必ず問いかけで締める**（Threads 最大の差別化）
   - 「皆さんはどうですか？」
   - 「同じような経験、ありますか？」
   - 「皆さんの工夫も教えてください」

2. **「私の体験」を前面に**
   - 翻訳だけだと「翻訳機」と思われる
   - 「私も最初は〜」「私のプロジェクトでは〜」を必ず入れる

3. **絵文字は内容に合わせて多様化**
   - 同じ絵文字（☺️ など）を連続使用しない
   - テーマ別マッピング:
     - Tips: 💡 / ✨
     - 速さ: ⚡ / ⏱️
     - 仕組み: 🔧 / ⚙️
     - 学び: 📚 / 📝
     - 思考: 💭 / 🧠
     - 失敗: 😅 / 🥲
     - 接続: 🔗
     - 設計: 📐
     - 一日: 🌱 / 🌙
     - 感謝: 🙏

4. **専門用語は必ず一文で解説**

5. **本名「石井」と「ミライ塾」は出さない**

6. **一人称は「私」**（「ひろ」は表示名のみ）

7. **CTAは控えめに、月1-2回**（Threads は売り込み嫌う文化）

## X とコンテンツを共有する場合

同じネタを X / Threads 両方に出すときの注意：

- **コピペ厳禁**：必ず訴求文を変える
- X: 短文・完結・情報密度
- Threads: 中文・問いかけ・体験＋共感

例：CLAUDE.md 200行制限の話

**X 用（v3.1・絵文字なし）**:
```
海外で話題の Claude Code Tips、面白かったので翻訳してみました。
「CLAUDE.md は 200行以下に。それ以上だと指示の遵守率が下がる」
私も最初、CLAUDE.md に色々詰め込みすぎて動作が不安定になった経験があります。
シンプルさが大事ですね。
```

**Threads 用（絵文字＋問いかけ）**:
```
海外で話題になっていた Claude Code Tips、
面白かったので翻訳してご紹介しますね💡

「CLAUDE.md は 200行以下に。
 それを超えると、Claude が指示を守る確率が
 測定可能なレベルで下がる」

私も最初、CLAUDE.md に色々詰め込みすぎて
動作が不安定になった経験があります…

シンプルに、本当に大事なことだけを書く。
これだけで安定感がぐっと変わりました。

皆さんも、CLAUDE.md でハマったこと、ありませんか？
```
